6. Việc phải làm ở phase sau

Trước khi bắt đầu Phase 1

  1. Quyết định Next.js 16 hay 15 (mục 4.2). Nếu giữ 16 thì sửa docs/architecture và cả 7 file plan cho khớp, đồng thời ghi vào harness rằng phải đọc node_modules/next/dist/docs/ trước khi viết code frontend.
  2. Push nhánh và xác nhận CI xanh — đóng nốt DoD mục 6 của Phase 0.
  3. Restart Claude Code nếu muốn Phase 1 chạy bằng 5 agent chuyên trách thay vì tuần tự.
  4. Vá 5 chỗ sai trong plan Phase 0 (mục 4.1 #1, #2, #4, #5, #6) vào file plan, để lần chạy lại không đi lại đúng con đường đó.
